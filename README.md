# Générateur d'images
Une application web qui génère des images à partir d'une description, avec une galerie des
créations.

## Ce que ça fait
- L'utilisateur décrit l'image qu'il veut
- L'application la génère et l'affiche
- Les images sont enregistrées et visibles dans une galerie

## Construit avec
Google AI Studio, Firebase
